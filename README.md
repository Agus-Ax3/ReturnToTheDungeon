# ReturnToTheDungeon

Work In Progress · Prototipo para el Parcial 1 de Motores de Desarrollo 1 – Unity Tecnicatura Universitaria en Desarrollo de Videojuegos – UTN

Descripción
Action roguelike en tercera persona. El jugador recorre una mazmorra de habitaciones conectadas por portales para llegar a la última sala, donde está la cura para la enfermedad de su hermana.

Controles
Acción	               Tecla
Moverse	                WASD
Mover la cámara    	    Mouse
Correr	                Shift
Saltar	                Espacio
Atacar	                Clic izquierdo
Interactuar       	    E
Reiniciar(al terminar)	R
